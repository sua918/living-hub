# ADR-0002: 초기 웹 인증은 서버 세션을 사용한다

- 상태: Accepted
- 날짜: 2026-08-05

## 맥락

초기 클라이언트는 Spring MVC와 Thymeleaf 기반 웹 브라우저다.
별도 모바일 앱이나 제3자 공개 API 요구는 없다.

## 결정

Spring Security의 세션 기반 폼 로그인을 사용한다.
CSRF 보호를 유지하고 운영 쿠키를 안전하게 설정한다.

## 결과

장점:

- 브라우저 기반 웹에 단순하다.
- 서버에서 세션 폐기와 로그아웃을 통제하기 쉽다.
- JWT 수명주기와 저장 문제를 초기 범위에서 피한다.

비용:

- 서버 측 세션 저장과 확장 전략이 필요할 수 있다.
- 별도 API 클라이언트가 생기면 인증 전략 재검토가 필요하다.

## 후속 조치

모바일 앱 또는 외부 API가 실제 요구가 되면
OAuth2/OIDC와 토큰 전략을 별도 ADR로 검토한다.
