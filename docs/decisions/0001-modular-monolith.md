# ADR-0001: 모듈형 모놀리스로 시작한다

- 상태: Accepted
- 날짜: 2026-08-05

## 맥락

서비스는 이슈, 할 일, 계약, 생활비, 식품 등 여러 기능으로 확장될 수 있다.
그러나 초기에는 한 명이 개발하고 운영하며, 독립 배포나 대규모 트래픽 요구가 없다.

## 결정

하나의 Spring Boot 애플리케이션과 PostgreSQL 데이터베이스를 사용한다.
기능별 최상위 패키지를 모듈 경계로 삼고 직접 내부 참조를 제한한다.

## 결과

장점:

- 배포, 디버깅, 트랜잭션이 단순하다.
- 운영 비용이 낮다.
- 기능별 구조를 유지하면 향후 분리 가능하다.

비용:

- 경계를 자동 검사하지 않으면 결합도가 증가할 수 있다.
- 하나의 프로세스 장애가 전체 기능에 영향을 준다.

## 후속 조치

- ArchUnit 또는 Spring Modulith로 경계를 검사한다.
- 모듈 간 공개 API와 이벤트를 문서화한다.
- 서비스 분리는 실제 운영 요구가 생길 때 새 ADR로 결정한다.
