# 도메인과 모듈 책임

## 1. 공통 언어

- **생활 이슈(Issue)**: 해결 또는 확인이 필요한 생활상의 문제
- **처리 기록(Issue Log)**: 이슈와 관련해 실제로 수행하거나 확인한 사건
- **다음 행동(Next Action)**: 이슈를 진전시키기 위해 해야 할 구체적 행동
- **할 일(Task)**: 특정 시점까지 수행해야 하는 행동 단위
- **출처(Source)**: 할 일이 만들어진 원본 기록과 규칙
- **거주지(Residence)**: 계약과 생활 이슈가 연결되는 생활 공간
- **계약(Contract)**: 거주지와 관련된 기간·금액·통보 조건
- **연락 기록(Communication)**: 특정 대상과 주고받은 내용 및 후속 연락 시점

## 2. 모듈

### identity

책임:

- 사용자 계정
- 인증 연동 식별자
- 계정 상태
- 사용자 시간대 및 기본 설정

소유하지 않는 것:

- 이슈, 할 일, 계약의 상세 데이터
- 다른 모듈의 권한 정책

### residence

책임:

- 거주지
- 거주지 별칭과 기본 정보
- 사용자의 거주지 소유 관계

불변식:

- 사용자는 자신이 소유한 거주지만 수정할 수 있다.
- 다른 모듈은 Residence Entity가 아닌 식별자를 사용한다.

### issue

책임:

- 생활 이슈
- 이슈 상태와 중요도
- 처리 기록
- 해결 정보

초기 상태 예시:

```text
OPEN
IN_PROGRESS
WAITING_EXTERNAL
ACTION_REQUIRED
ON_HOLD
RESOLVED
```

상태 전이는 도메인 메서드로 수행한다.
임의의 문자열 상태 변경을 허용하지 않는다.

### task

책임:

- 직접 생성 할 일
- 다른 모듈에서 파생된 후속 할 일
- 기한, 완료, 취소
- 반복 규칙은 2차 범위

불변식:

- 소유자 없는 할 일은 없다.
- 자동 생성 할 일은 출처를 가진다.
- 완료된 할 일의 완료 시각을 보존한다.
- 같은 출처 규칙의 중복 생성을 방지한다.

### dashboard

책임:

- 오늘 할 일
- 기한 초과
- 답변 대기 중 이슈
- 임박한 계약 또는 납부 항목
- 최근 활동

Dashboard는 다른 모듈의 상태를 변경하지 않는 읽기 중심 모듈이다.

### contract

책임:

- 계약 기간
- 보증금·월세·관리비
- 납부일
- 통보 기한
- 특약 메모와 파일 참조

법률 판단을 제공하지 않는다.
사용자가 입력한 조건과 계산 근거를 명확히 보여준다.

### finance

책임:

- 고정비
- 지출
- 예산
- 이슈·계약과의 선택적 연결

은행 계좌 연결과 결제는 초기 범위가 아니다.

### food

책임:

- 구매·조리·냉장·냉동·해동 시점
- 보관 위치
- 사용자 지정 확인일

안전 섭취 가능 여부를 확정 판정하지 않는다.

### communication

책임:

- 연락 대상
- 보낸 내용과 받은 답변
- 연락 시각
- 다음 연락 예정일
- 메시지 템플릿

실제 외부 발송은 별도 승인 흐름 없이는 하지 않는다.

### notification

책임:

- 알림 요청
- 채널별 전송 상태
- 재시도와 실패 기록
- 사용자 알림 설정

도메인 규칙을 소유하지 않고, 다른 모듈이 결정한 알림 의도를 전달한다.

## 3. 모듈 간 대표 이벤트

```text
IssueFollowUpRequested
IssueResolved
TaskDueSoon
ContractNoticeScheduled
PaymentDueScheduled
CommunicationFollowUpRequested
```

이벤트 이름은 이미 일어난 사실 또는 명확한 요청을 표현한다.

## 4. 주요 관계

```text
User 1 ─ N Residence
User 1 ─ N Task
Residence 1 ─ N Issue
Issue 1 ─ N IssueLog
Residence 1 ─ N Contract
Issue 0..1 ─ N Expense
Issue 0..1 ─ N Communication
```

다른 모듈 간 관계는 객체 그래프보다 식별자로 연결한다.
모든 관계를 JPA 양방향 연관관계로 만들지 않는다.
